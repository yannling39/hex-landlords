# hex-landlords

TypeScript 斗地主项目，包含规则引擎、确定性命令行演示和浏览器单机 MVP。浏览器版由玩家 A 对战两个本地 AI，可完成三手 Run。

## 浏览器游戏

```sh
npm install
npm run dev
```

打开 Vite 输出的本地地址即可开始。默认开发端口为 `5173`；端口被占用时 Vite 会选择其他可用端口。

- 轮到玩家 A 叫分时，可选择不叫或当前有效的分数。叫到 3 分后确定地主并公开底牌。
- 轮到玩家 A 出牌时，点击或横向拖动手牌选牌，再点“出牌”；跟牌时可选择“不出”。不合法的出牌会显示规则提示并保留当前选择。两人连续不出后会清空当前选牌。
- 手牌按点数从小到大排列，同点数按梅花、方块、红桃、黑桃排列，大小王在末尾，大王使用红色牌面。窄屏可横向滚动手牌。
- 牌桌显示当前行动者、桌面牌、每名玩家最近出的牌或“不出”、底牌公开状态、倍数、玩家剩余牌数、Run 分数和公开对局记录。每次出牌会展示约 1 秒再继续。
- 每手结束后显示本手结算，可继续下一手；三手完成后显示 Run 结果。任意阶段都可重开。
- 浏览器每次开始或重开都会生成新的随机种子；需要复现牌局时可在代码中为 `LocalGameClient` 传入固定种子。

当前浏览器版为单机 MVP：AI 在本地运行，不支持联网对战或牌局存档；海克斯强化默认关闭。

## 规则与架构

规则入口为 `src/domain/game.ts` 的 `dispatch(state, command)`；创建 Run 使用 `src/domain/setup.ts` 的 `createRun({ seed })`。对外提供状态时使用 `viewForPlayer(state, playerId)`，不要直接发送完整内部状态。浏览器 UI 通过 `src/web/game-client.ts` 的 `GameClient` 边界读取玩家视图并提交命令，为后续替换为远程房主客户端保留接口。

开工版 GDD 见 [docs/GDD-v1.2-开工最终版.md](docs/GDD-v1.2-开工最终版.md)。
