# 2026-09-27 海克斯玩法进展

- 将一个 Run 调整为六手，首叫位依次为 A、B、C、A、B、C；每名玩家在第 1、3 手开始前各抽取一个海克斯，能力累计至本 Run 结束。
- 确定六项海克斯的规则与状态边界：共鸣、断章、弃守、逆流、同色协定、尊我为王。两张尊王牌作为单张时同级，不能互压。
- 规则引擎加入特殊出牌声明、每手资源重置、尊王牌指定、逆流墩模式及弃守弃牌；合法行动枚举和本地 AI 已接入六项能力。
- 浏览器支持海克斯抽取与尊王牌指定。逆流持有者领出单张或对子时可勾选“发动逆流”；桌面会显示逆流状态，并按倒序规则判断出牌按钮是否可用。
- 玩家可以在出牌操作区声明共鸣、断章、同色协定；跟牌时可用选中的单张牌发动弃守。出牌预览与提交使用相同的领域解析规则，日志显示特殊出法。

详细规则见 [六手 Run 与个人海克斯规则规格](superpowers/specs/2026-09-27-six-hand-hex-rules-design.md)，实施进度见 [实现计划](superpowers/plans/2026-09-27-six-hand-hex-implementation.md)。
